## Trying requests

Each operation has a **Try it** panel. Requests go straight from your browser to the
selected server, so you need a token for that API:

- **Backend and Ops** take `Authorization: Bearer <JWT>` — the same token the portal session
  carries.
- **Call Service** endpoints that need auth take the internal token.

This site is backed by **staging**. You sign in with your staging portal account, the
reference is built from the services' `staging` branches, and **Try it** sends requests to the
staging servers. If a rebuild fails, the previous version stays up until the next successful
one.

## Signing out

Your docs session lasts 12 hours. To end it sooner, open `/_auth/sign-out` on this site.
